# 記事ファクトチェック 第1弾（2026-10-30）

読者指摘（研究ダイジェスト Vol.5 の嗅覚の数字）をきっかけに、研究ダイジェスト 32 本と安全に関わる解説記事 20 本を点検した結果。
各論文の要旨・全文（PMC 等）、環境省・消費者庁・米 NPS の指針と照合した。修正は未着手（Vol.5 のみ e668566d で訂正済み）。

重大度: 【誤】すぐ直す / 【確】要確認 / 【調】表現の調整

## A. 安全に関わる解説記事（最優先）

### encounter
- 【誤】L110,113,147,151 ヒグマは「動かないフリは通用しない」「初手から反撃前提」→ NPS・北海道・自サイト playing-dead と逆。防衛的攻撃はうつ伏せ防御姿勢、捕食的（執拗・引きずる・テント侵入）なら反撃。
- 【調】L36,44 「10m以下ならスプレー — もしくは伏せる」→「10m以下はスプレーを構える。接触が避けられないときに防御姿勢」
- 【確】L122,167 「容量230g以上・射程5m以上」→ 環境省要件（噴射距離7.5m程度以上・噴射時間6秒以上、容量は基準にしない）に揃える
- 【調】L102 ヒグマ成獣は木登りが得意ではない / L177「必ず母グマがいる」→「可能性が高い」

### first-aid
- 【誤】L101,103,176 止血帯を「定期的に緩める」「パラコードで縛る」→ 一度締めたら緩めない、幅広の専用止血帯、締めた時刻を記録。パラコード削除。
- 【誤】L139 「ヒグマは狂犬病保菌の可能性ゼロではない」→ 国内では1957年以降発生なし。リスク極めて低い、要否は医師判断。
- 【調】L96 圧迫「5〜10分」→「止まるまで10分以上」/ L178,182 消毒液より流水洗浄、大出血時にNSAIDsは避ける
- 【確】L202 「AndroidPaR」は誤記 / L35,45 救助「30〜90分」出典なし

### bluff-charge
- 【誤】L98 「無音で耳を倒し、低姿勢で一直線＝捕食型」→ これは防衛的な本気の攻撃の典型。接触されたら防御姿勢。
- 【調】L88 ブラフ寄り/本気寄りの両方に「頭を低く」
- 【確】L36,45,73,203 「5〜10m手前で急停止」「70〜80%がブラフ」出典なし（L147は3m）/ L112,206 「5mまで近づいたら噴射」/ L151

### night-encounter（meta description/lead も）
- 【誤】L35,45,72 「薄明薄暮（夕方〜夜明け）」「日没1時間前〜夜明け2時間後が中心」→ 薄明薄暮は朝夕。ツキノワグマは基本昼行性で朝夕に活発。
- 【確】L38,45,81 夜間は捕食型が多い / L77 夜間視覚は犬と同等 / L98-100,140 ライトで視覚を麻痺・ストロボ
- 【調】L160,169 テント内は「立ち上がる」→ NPS は「テントで襲われたら反撃」

### bear-report
- 【誤】L253 「自衛隊派遣要請（2025年改正法で市街地での猟銃使用が一部容認）」→ 緊急銃猟（2025年9月施行、市町村長判断）と自衛隊の後方支援を分けて書く。
- 【確】L274,277 札幌市のLINE通報、「くまっぷ・くまMap」の実在

### cub-handling
- 【調】L34,43,68-70 「単独の子グマはあり得ない」がL160の孤立子グマ節と矛盾 / L36,49,meta「0.5秒」根拠なし / L69 親離れ年齢 / L91-92 母グマが樹上 / 【確】L177 割合

### urban-encounter
- 【調】L146,154 110番の基準（50m以内）が bear-report と食い違い → 市街地は距離にかかわらず110番 / L183,191,257 「数日間戻る」断定 / L99-100 柵・ガラスを退避先にしない / L127,166 「捕食動機」→ 防衛的攻撃

### playing-dead
- 【調】L174-175 「ほぼ必ず捕食攻撃」/ L255-256 スプレーは「生存率が高い」→「使用者の約98%が無傷（Smith 2008）」/ 【確】L70-72 由来の説明

### bear-spray
- 【誤】L35,43,83,meta 「射程5m以上」→ 7.5m程度以上 / L35,43,79 「容量230g以上」→ 容量でなく噴射距離・時間・CRC% / L49 「至近（2〜5m）」→ 5〜10m（消費者庁）
- 【調】L71-72 92%（Smith 2008）と銃76%（Smith 2012・長銃のみ、拳銃84%）は別調査 / L117 「ほぼ確実に」/ 【確】L204 期限切れを練習に使う → 環境省は実物試射を推奨しない

### weapons
- 【誤】L74,166 「護身用とされ合法」「公の場で問題なし」→ 正当な理由なき携帯は軽犯罪法の対象になりうる、環境省は安易な持ち歩きを戒める
- 【誤】L170 「非殺傷性なので人間にも安全」→ 人には絶対に向けない（環境省）
- 【確】L156 子グマに石を投げる / 【調】L144 銃との比較

### repellent-comparison
- 【誤】L172 「一気に6〜9秒で噴射し切る」→ bear-spray（1〜2秒ずつ）と逆 / L171,173 射程5〜8m・容量が大きいほど信頼 → 環境省要件
- 【調】L168,317 出典の取り違え（銃比較は Smith 2012）/ 【確】L311 電気柵80〜95%減

### spray-travel（meta も）
- 【誤】L85 「唐辛子成分2%以上」→ CRC 1〜2%程度
- 【確】L107-112 JR の持ち込み条件（2025年4月の規則改正後を各社に確認、新幹線で誤噴射事例あり）/ L153,158 宅配
- 飛行機は持ち込み・預け入れとも不可 → 正しい
